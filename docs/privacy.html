Privacy policy

Last updated 2 October 2026.

Boring Tracker collects no data. There is no analytics, no crash reporting, and no copy of anything you type anywhere but on your own device.

The app is open source under the MIT licence, so you can check this policy against the code itself instead of taking it on trust.

No servers, no network

The app has no backend and no account system. It contains no networking code at all, so nothing you enter can leave your device unless you export it yourself.

The one link out is the Source on GitHub row on the About screen. Tapping it opens GitHub in your browser, which sends nothing from the app along with it.

What is stored, and where

Everything lives on your device, inside the app's own container:

  • Your trackers and entries, in a single JSON file (Application Support/boring-tracker/store.json), with a backup copy next to it in case a write goes wrong.
  • Three preferences: light or dark appearance, the hour your day starts, and which group of trackers you used last.

The app asks for no system permissions. It does not use the camera, photo library, contacts, location, health data, or notifications.

Deleting the app deletes all of this. There is no copy anywhere else.

Export and import

Export writes your data to a JSON or CSV file and hands it to the standard iOS share sheet. You choose where it goes. The app never sends anything on its own. Import reads a file you pick.

Once an exported file is somewhere else, the terms of that place apply. If you mail an export to yourself, it is in your mail provider's hands, outside this app and this policy.

Device backups

The store file is not excluded from device backups, so if you back up your iPhone to iCloud or to a computer, your Boring Tracker data is included, the same as other apps' data. That happens under Apple's terms, not the app's.

Children

The app collects nothing from anyone, including children. It has no accounts, no ads, no messaging, and no content served from a server.

Changes to this policy

If the app changes in a way that makes a sentence here untrue, this page changes with it. The page is a file in the public repository, so every version and its date are in the history.
